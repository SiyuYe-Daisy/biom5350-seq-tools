# BIOM5350 Sequence Tools

This script calculates base composition for DNA sequences in a FASTA file.

## Usage

Run `python gc_content.py example.fasta`.

The script reports each sequence’s length, GC%, and AT%, followed by the mean GC% across all sequences.
